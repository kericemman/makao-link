# MakaoLink

MakaoLink is a rental housing platform designed to simplify property discovery for tenants and streamline listing management for landlords and agents in Kenya.

The platform eliminates WhatsApp and Facebook listing chaos by providing a structured, verified, and subscription-based rental ecosystem.

---

## Vision

To build Kenya’s most trusted rental discovery and property listing platform.

---

## Tech Stack

### Frontend

- TailwindCSS
- React Router
- Axios

- Zod
- React Hot Toast

### Backend
- Node.js

- Resend (email notifications)
- Paystack / Daraja API (payments)

---

## User Roles

### 1. Tenant
- Browse listings
- Filter properties
- View property details
- Send inquiries

### 2. Landlord / Agent
- Create account
- Pay monthly subscription
- List properties
- Manage listings (CRUD)
- Receive inquiries via dashboard + email
- Reset password
- Contact admin

### 3. Admin
- Approve / reject listings
- Suspend accounts
- Verify payments
- Handle support queries
- Manage blog posts
- Verify landlord KYC

## Roadmap

### Foundation Release
- Shared identity, roles, organizations, memberships and property mandates
- Listing integrity, moderation and secure media workflows
- Canonical property request and viewing foundations

### Connected Marketplace Release
- Customer requests matched to eligible, published inventory
- Inquiry and lead progression across website and mobile app
- Authorized viewing requests, confirmation and outcomes
- Landlord and agent workflows using shared backend records

### Renda Assistant Release
- Safe property search and request workflows through Renda Assistant
- Conversation persistence, consent and authorized actions
- WhatChimp notifications and human handoff after provider verification

### Professional and Company Release
- Advanced organizations, teams, building/unit inventory and lead assignment
- Portfolio reporting based on verified operational outcomes
